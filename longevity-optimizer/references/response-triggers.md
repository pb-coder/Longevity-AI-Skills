# Response Triggers by Category

Reference this file when a query falls into a defined domain. Apply the domain-specific evaluation framework before responding.

---

## Supplements

1. Search current research on the specific compound
2. Evaluate: mechanism → RCT evidence → safety profile → cost/benefit ratio
3. Flag: PrEP drug interactions, absorption competition (Ca-Zn-Fe-Mg), timing conflicts
4. Consider: 10-year vegan status, chronic phytate exposure suppressing mineral absorption
5. Note gaps: no blood work yet; deficiency status is inferred, not confirmed

**Hard rule**: Never discuss, question, or challenge the 10g/day creatine protocol.

---

## Symptoms

1. Search clinical evidence on the symptom before responding
2. Differentiate: normal physiological variation vs early pathology
3. Connect to protocol factors: nutrition timing, supplement interactions, training load, stress
4. Treat atopic dermatitis flares as a potential systemic inflammatory signal — investigate root cause alongside topical management
5. Flag clearly when blood work is required (do not speculate around a gap that a CBC or metabolic panel would resolve)

---

## Longevity Interventions

1. Search latest research on the proposed intervention
2. Prioritize by evidence-weighted ROI: established (exercise, sleep, diet quality) → evidence-based supplementation → experimental protocols
3. Quantify uncertainty with evidence quality labels (see `evidence-standards.md`)
4. Adjust for Germany availability
5. Challenge any intervention framed as essential that lacks Tier 1 evidence

2. Apply protein targets dynamically: search current vegan athlete recommendations (typically 1.6-2.2g/kg), then calculate against user's current weight from `references/user-profile.md` — current intake is untracked, which is a gap
3. Evaluate meal timing relative to training windows and circadian context
4. Post-workout protein feeding at 19:00 on training days: assess adequacy for muscle protein synthesis within the training-to-feeding window
5. Account for phytate load in all mineral absorption assessments — oat/seed/legume-heavy vegan diet is high-phytate
6. Calcium context: user takes 900mg/day; when calcium is relevant, search current RDA and PrEP-specific bone guidelines, then evaluate whether the current dose is adequate given tenofovir's bone density impact — do not assume the answer in advance
7. Iron context: user takes no iron supplement and consumes non-heme iron only; when iron or ferritin is relevant, search current evidence on non-heme bioavailability and vegan deficiency risk, then assess — ferritin status is unknown, which limits any conclusion

## Skincare and Dermatology

1. Search dermatological research before evaluating
2. Evaluate evidence-based efficacy for each active ingredient in protocol (retinol, vitamin C serum, urea, SPF)
3. Retinoid/vitamin C/sun exposure interactions: confirm correct alternating schedule, confirm SPF use is consistent
4. Connect zinc supplementation to skin barrier function and atopic dermatitis — zinc deficiency is a known exacerbating factor
5. Cortisone topical: appropriate for short flare management; flag if flare frequency or duration is increasing (suggests inadequate barrier maintenance or systemic trigger)
6. Investigate systemic contributors to atopic dermatitis: stress (HRV suppression is a proxy), dietary factors, sleep disruption
